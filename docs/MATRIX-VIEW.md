# 人员 × 日期排班表（衔接原 Excel 工作流）

主管原来用 Excel 手工排班，结构是「姓名 × 日期」，格子里写岗位代码、`V` 表示休息。
系统原来的总览是「岗位 × 日期」卡片，只能看到"谁上班"，看不到"谁休息"，
也无法直接和原表对照。本次增加人员矩阵视图，界面与导出都对齐原表。

## 1. 展示口径

| 格子内容 | 含义 | 颜色 |
| --- | --- | --- |
| `B2` | 当值主管（每日唯一） | 红色加粗 |
| `A2` / `B1` | 早班 / 晚班辅助主管 | 紫色加粗 |
| 其他岗位代码（`A3`、`B8`…） | 普通岗位 | 深灰 |
| `V` | 休息（在职但当日未排班） | 浅灰 |
| `假` | 已批准请假（`availability_requests`，status=approved） | 琥珀色 |
| `-` | 员工已停用 | 浅灰 |

- 行序：主管在前，其余按导入顺序（`employee.id`），和手工表习惯一致；主管姓名底色浅橙。
- 列序：按版本起止日期连续排列，当天所在列淡黄底。
- 表尾三行：上班人数、休息人数、请假人数（有请假时才显示）。
- 悬停任一格可看到「岗位名称 · 角色 · 早/晚班 · 人工预排/自动排班 · 是否锁定」。

## 2. 数据来源与"休息"的推导

`GET /api/schedule/versions/{version_id}/matrix`（`backend/app/services/matrix.py`）

```
行  = 在职员工 ∪ 本版本有排班的员工（停用后仍有排班的也要出现，避免"有班无人"）
格  = 有 ScheduleAssignment → work
      否则有已批准请假      → leave
      否则停用              → inactive
      否则                  → rest
```

休息人员不在 `schedule_assignments` 里，只能由「在职员工 − 当日已排」推导，所以这段
推导只写在 `matrix.py`，前端表格与 Excel 导出共用，避免两处口径漂移。

请假优先于休息：某人当天有已批准请假且未排班，显示 `假` 而不是 `V`，便于主管核对
"休息"与"请假"两种不同的人力缺口原因。

## 3. 界面

- 总览页新增视图切换：**人员表格**（默认）/ 岗位卡片，选择记在 `localStorage`，
  也支持 `/?view=table`、`/?view=cards` 强制指定。
- 人员表格支持按姓名搜索、仅看主管；表头与姓名列固定，30 天窗口横向滚动不丢上下文。
- 岗位卡片视图每天底部补一行「休息 N 人：…」与「请假 N 人：…」。
- 自动排班完成后，「查看人员表格」直接落到矩阵视图。

## 4. Excel 导出

导出的第一张工作表 `人员排班` 与原表同构：

```
        2026-10-25  2026-10-26 …      ← 日期行（红色）
星期＼姓名  星期日      星期一      …      ← 星期行
黎森榕      A2          V
李甜娟      B3          B1
```

- 第一列姓名、第二列起为日期，`V`/`假` 与原表一致，可直接整块贴回原工作簿。
- 其余工作表（`排班表` 明细、`岗位覆盖`、`每日统计`、`员工明细`、`主管公平`、`版本信息`）保持不变。
- 导出只读，不修改任何排班数据。

## 5. 与后续"导入历史排班表"的衔接

矩阵的键就是 `(work_date, employee_id)`，与 `schedule_assignments` 一一对应：

- 导入历史表时，逐格读取：`V` 跳过，`假` 跳过并可选生成请假记录，岗位代码写入
  `position_code`，落到一个新版本（`status=published`，用于公平/轮换历史口径）。
- 因为展示层直接用这个键，导入后无需再改前端或导出逻辑。
